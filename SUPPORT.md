# Supporting sapper

sapper is free and Apache-2.0 licensed. If it saved you from a bad backup,
you can support its development.

## USDT

Send USDT only on the network named next to each address. Tokens sent on the
wrong network are lost and cannot be recovered.

| Network | Address |
|---|---|
| TRON (TRC-20) | `TEntyXNGPx56ckeuBawD2B6Di9wyWzfEhn` |
| Ethereum (ERC-20) | `0xb36377938b0139068e75ed0346a751632b1ef83f` |

These are the only addresses. The project will never message you asking for
payment, and anyone who does is not the maintainer. Check an address against
this file in the repository before you send.

For setup help, support contracts, or sapper Pro, open an issue titled
